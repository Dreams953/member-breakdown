# 優秀研究賞 集計・ランキングツール

様式2「個人票」（優秀研究賞 一次審査用集計表）を集約し、ブラウザ上でランキング表示するための一式です。

> **事務局PCにPythonを入れられない場合は、ブラウザだけで完結する `award-tool.html`（後述）を使ってください。**
> インストール不要・データは外部に送信されません。Python版（`aggregate_xlsx.py`）はバッチ処理向けの代替手段です。

## 構成

| ファイル | 役割 |
|---|---|
| **`award-tool.html`** | **【推奨・Python不要】** これ1つを開くだけで「Excel集計＋ランキング表示」が完結 |
| `aggregate_xlsx.py` | （代替）提出xlsx群を集計して `data_award.json` を出力するPythonスクリプト |
| `award-ranking.html` | （旧）表示専用。`data_award.json` を読み込んで表示 |
| `make_dummy.py` / `data_award.sample.json` | デモ用ダミーデータ |
| `award-tool.src.html` / `build_award_tool.sh` / `vendor/` | `award-tool.html` の元ソースと再ビルド用 |

---

## ★ 推奨：ブラウザ版 `award-tool.html`（インストール不要）

1. **提出ファイルをフォルダに並べる**（所属はフォルダ名から判定）
   ```
   提出ルート/
     理工学部/
       機械工学科/
         研究者まとめ.xlsx   ← ①タブ分割でも
         佐藤太郎.xlsx        ← ②1人1ファイルでも、どちらも可
     情報工学部/
       情報科学科/
         ...
   ```
2. **`award-tool.html` をダブルクリック**してブラウザで開く
3. 右上 **「📁 提出フォルダを読み込む」** → 上記「提出ルート」フォルダを選択
   → ブラウザ内だけで集計し、ランキングが表示されます
4. 必要に応じて **「⬇ JSON保存」** で集計結果（`data_award.json`）を保存。
   次回は **「📂 JSON読込」** で即表示できます。

> - すべてローカル動作です。業績ファイルやJSONは外部に送信されません。
> - 対応ブラウザ：Google Chrome / Microsoft Edge を推奨（フォルダ選択に対応）。
> - 集計時に出る **「⚠ 要確認」** は記入漏れ・所属不明・氏名重複です。該当を直して再読込してください。

## （代替）Python版 `aggregate_xlsx.py`


```bash
pip install openpyxl

# 1) 集計（提出ルート配下を再帰探索して JSON 出力）
python aggregate_xlsx.py --dir ./提出ルート --out data_award.json

# 2) 表示（award-ranking.html をブラウザで開き「📂 読み込む」で data_award.json を選択）
#    ※ data_award.html と同じ場所に data_award.json を置けば自動読込も可

# 困ったとき：1ファイルの中身を診断
python aggregate_xlsx.py --debug ./サンプル.xlsx
```

### 推奨フォルダ構成（所属はフォルダ階層から取得）

ファイル内に所属情報が無いため、所属は**フォルダ名**から判定します。

```
提出ルート/
  理工学部/
    機械工学科/
      研究者まとめ.xlsx      ← ①タブ分割（1ファイルに複数研究者タブ）
      佐藤太郎.xlsx          ← ②ファイル分割（1人1ファイル）
  情報工学部/
    情報科学科/
      ...
```

- `<学部>/<学科>/` の2階層を所属として読み取ります。
- 学科だけの1階層でも可（内蔵の学科→学部対応表で学部を補完）。

## ランキング画面でできること

- **フィルタ**：学部／学科（学部に連動）／職位
- **ランキング対象の切替**：合計・各部門（論文／学術／アクティビティー）・各項目
- **母集団の切替**：全体／学部内／学科内（学部単位・学科単位の表彰タイトルに対応）
- 順位表（メダル表示）・バー・サマリーカード、列クリックで並び替え

## 事務局へのお願い（分析前の最低限の整理）

現状、提出データには所属が無く氏名のみ・形態も混在しているため、集計精度を上げるには
**提出前の最低限の整え**が重要です。優先度順に整理します。

### 必須（これが無いと正しく集計できない）

1. **Excel で開いて保存してから提出**
   数式が未計算（`#DIV/0!` 等）のままだと点数が 0 として扱われます。
   → 提出前に一度 Excel で開き、上書き保存。
2. **所属でフォルダ分け**：`学部/学科/` の階層に配置（所属はここから取得）。
3. **氏名を必ず記入**：フォーム内の氏名セル、または最低でも**タブ名／ファイル名を氏名**に。
   「様式2 (個人票)」のままにしない。

### 強く推奨（重複・取り違え防止）

4. **教職員ID等の一意キーを付与**：同姓同名や二重提出を機械的に判別できるように。
   （現状は氏名重複を warning で検知しますが、人手確認が必要です）
5. **1人＝1シート（様式2）に統一**：ファイル分割／タブ分割どちらでも可。
   1シートに複数人を詰め込まない。
6. **様式（行・列構成）を改変しない**：行挿入・列追加・セル結合の変更をしない
   （集計表の位置がずれると抽出に失敗します）。

### あると望ましい（表記ゆれ対策）

7. **職位表記の統一**：例「P（教授）」のような記号＋括弧の表記を一本化。
8. **半角／全角・空白の統一**。

> 集計スクリプトは、読み込み失敗・所属不明（フォルダ直下）・氏名重複を
> `data_award.json` の `meta.warnings` と標準エラー出力に一覧化します。
> まずはこの warning がゼロになるよう整えるのが、実運用の最短ルートです。
