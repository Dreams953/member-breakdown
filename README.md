# 研究業績 BIダッシュボード（東京都市大学 研究者情報DB）

東京都市大学の公開「研究者情報データベース」
（<https://www.risys.gl.tcu.ac.jp/>）のデータをもとに、
**所属別**に **研究業績／教育業績／社会貢献業績** を可視化する、
ブラウザだけで動く BIツールです。項目（カテゴリ）ごとに **対象年度（期間）** を選択できます。

## 構成ファイル

| ファイル | 役割 |
|---|---|
| `research-bi.html` | BIツール本体。**サーバー不要**。ブラウザで開くだけで動作します |
| `scraper.py` | 公開DBを巡回し `data.json` を生成する収集スクリプト |
| `data.sample.json` | データ仕様（JSONスキーマ）の確認用サンプル |

## 使い方

### 1. すぐ試す（デモデータ）
`research-bi.html` をダブルクリックしてブラウザで開きます。
`data.json` が無ければ、構造を模した**デモデータ**で全機能を確認できます。

### 2. 実データで使う
1. お手元のPCで収集スクリプトを実行して `data.json` を作成します。
   ```bash
   pip install requests beautifulsoup4
   # (推奨) 所属一覧から全学を自動収集
   python scraper.py --discover --out data.json
   # まず1人で動作確認したいとき
   python scraper.py --discover --limit 1 --out data.json
   # 研究者ID(tchCd)一覧から収集したいとき（ids.txt は1行1ID）
   python scraper.py --ids ids.txt --out data.json
   ```
2. `data.json` を `research-bi.html` と同じフォルダに置く、
   または画面右上の「**data.json を読み込む**」ボタンでファイルを選びます。
   （`file://` で開くと自動読込が効かない場合があるため、ボタン読込が確実です）

> ⚠️ 収集スクリプトは、対象サイトの利用規約・robots.txt を確認のうえ、
> 低速・少回数（既定で1秒間隔）でご利用ください。

#### スクレイパが対応しているサイト構造
- 業績はタブ（別ページ）に分かれています：
  研究業績 `action=01` ／ 教育業績 `action=02` ／ 社会貢献業績 `action=04`
- 各ページ内の `<table class="TBL-glist02">` を解析し、種別見出し（論文／MISC／
  講演・口頭発表等／研究課題／産業財産権 …）・年（`YYYY年`）・タイトルを抽出します。
- 所属一覧 `action=position` の学部コード（`Facultyk`）から研究者一覧を巡回します。
- **学科（department）・職名（position）** は基本情報ページ（`action=profile`）から取得します。
  「所属」欄の1行目（例：`理工学部 機械工学科`）の先頭を学部、続きを学科とし、「職名」欄を職名とします。
  （1人あたり 基本情報＋業績3ページ＝計4ページ取得するため、収集時間は学部のみ版より少し長くなります）

## できること

- **所属フィルタ**：学部 → 学科（連動）／職名で絞り込み（全カテゴリ共通）
- **項目別 対象年度**：研究／教育／社会貢献それぞれに開始〜終了年を指定。ON/OFF も可
- **KPIカード**：対象研究者数・各カテゴリ件数・1人あたり総業績
- **可視化**：
  - 所属（学部）別 業績件数（カテゴリ積み上げ）
  - 年度別 業績推移（カテゴリ別 折れ線）
  - カテゴリ構成（ドーナツ）
  - 業績種別 内訳（論文／著書／学会発表 …）
  - 学科別 業績件数 Top15
  - 学部別 1人あたり業績数
  - 所属別 研究者数

## データ仕様（`data.json`）

```jsonc
{
  "meta": { "categories": ["研究業績", "教育業績", "社会貢献業績"] },
  "researchers": [
    {
      "id": "7000118",
      "name": "氏名",
      "faculty": "情報工学部",      // 学部（所属の上位）
      "department": "情報科学科",   // 学科（所属の下位）
      "position": "教授",           // 職名
      "url": "…/Main.php?action=01&tchCd=7000118&type=detail",
      "achievements": [
        { "category": "研究業績", "type": "論文", "year": 2023, "title": "…" }
      ]
    }
  ]
}
```

`category` は3カテゴリのいずれか、`year` は西暦（数値）、`type` は種別（任意の文字列）。
この形式に合っていれば、出典を問わず読み込めます。

## 補足：データ取得について

このリポジトリを生成した自動実行環境からは、対象サイトへ直接アクセスできません
（環境のネットワーク許可リスト外、かつサーバー側が自動アクセスを拒否）。
そのため収集はお手元の環境での実行を前提としています。実ページのHTMLを共有いただければ、
`scraper.py` のパース処理を実データに合わせて確定版に仕上げられます。
